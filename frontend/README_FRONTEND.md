# UmRus Frontend

Актуальный frontend — многоточечное React/Vite-приложение:

- `/` — пользовательское приложение для Telegram WebApp и обычного браузера;
- `/form/` — компактный редактор теории и упражнений;
- `/api/*` — запросы к FastAPI через reverse proxy или Vite proxy.

## Структура

```text
src/
├── main.jsx                 # пользовательская точка входа
├── App.jsx                  # маршруты, каталоги и PracticeSession
├── app.css                  # тема и пользовательский интерфейс
├── BrandLogo.jsx            # общий логотип
├── theory/
│   ├── TheoryRenderer.jsx   # единый рендерер TheoryBlock
│   └── theory.css
└── form/
    ├── index.jsx            # точка входа /form/
    ├── FormApp.jsx          # редактор контента
    └── form.css
```

`TheoryRenderer` используется и учеником, и предпросмотром формы. Отдельных
рендереров теории быть не должно: новый тип блока добавляется в его registry-like
ветку и в набор полей редактора.

Практика работает через серверную `PracticeSession`. Frontend не получает
правильные ответы до отправки попытки и не проверяет их самостоятельно.

## Состояние

- URL — текущий раздел, задание, тема или сессия;
- API — опубликованный контент и состояние PracticeSession;
- `sessionStorage` — идентификатор текущего Telegram-пользователя и позиции
  прокрутки;
- `localStorage` — клиентский идентификатор практики и неотправленные ответы
  активной сессии.

## Темы

По умолчанию используется тёмная тема. В Telegram она синхронизируется с
`Telegram.WebApp.colorScheme`, в браузере — с `prefers-color-scheme`.
Основные токены определены отдельно в `app.css` и `form.css`; общий рендерер
теории использует эти токены без собственной палитры.

## Локальный запуск

```bash
npm install
npm run dev
```

По умолчанию Vite проксирует `/api` на `http://127.0.0.1:8000`. Другой адрес
можно задать через `VITE_API_PROXY_TARGET`.

## Проверки

```bash
npm run lint
npm run build
```

Перед публикацией необходимо проверить пользовательское приложение и `/form/`
в светлой и тёмной темах, как минимум на мобильной и десктопной ширине.
