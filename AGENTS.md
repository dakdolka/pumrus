# Правки учебной теории

При запросах пользователя изменить учебное содержимое Пумрус:

1. Сначала экспортировать запрошенную тему через `/api/v2/admin/theory-documents/{id}/edit-package` или кнопку «Экспорт темы» в форме. Изучить текущие блоки, вложенность и заметки.
2. Проектировать изменения относительно этой выгрузки. Не подменять опубликованную тему исходным текстом из репозитория. Если рабочая выгрузка недоступна, явно обозначить это; пример можно подготовить как преобразование текущей темы на сервере.
3. Возвращать пакет `pumrus.theory-edit`, версия 1. Сохранять `base` и `before`, изменять только `after`. Формат и примеры описаны в `docs/theory-edit-packages.md`.
4. Пользователь вставляет пакет в «Изменения по коду», сравнивает страницы, при необходимости редактирует блоки результата и применяет изменения кнопкой. Для таких правок предпочитать этот путь отдельным скриптам прямой записи в БД.

Эти правила относятся к учебному содержимому, а не к обычным изменениям кода приложения.
