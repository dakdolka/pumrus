# Аудит опубликованной теории ЕГЭ‑2026

Снимок: 16 сентября 2026 года. Источник текущего содержания — публичные маршруты
`/api/v2/catalog/tasks/{number}` и `/api/v2/theory/topics/{id}` на bestgreen.ru.
Эти маршруты показывают только опубликованные и открытые темы. Позднее полный
административный экспорт проверен с предоставленным владельцем временным ключом:
`/api/v2/admin/exports/theory?include_history=true` включает темы в статусах
`published`, `published_manual`, `deprecated` и `deleted`, а также все версии
документов и блоков. На момент проверки в нём 277 тем, 304 документа,
725 версий и 3400 блоков. Ключ в репозитории не сохраняется.

## Проверенные исправления, подготовленные к публикации

Скрипт `backend/app/scripts/revise_theory_2026.py` делает новый опубликованный
слепок, оставляя предыдущую версию для сравнения. Перед записью проверяет
исходный текст каждого изменяемого блока; если редактор успел его поменять,
скрипт останавливается без частичной публикации.

| Задание | Что исправляется |
| --- | --- |
| 1 | Вместо совета «чувствовать контекст» — проверяемые смысловые связи и грамматическая форма. |
| 3 | Удаление пустого видимого блока. |
| 4 | Различение ударений «отзы́в посла» и «о́тзыв о книге». |
| 7 | Расширение до грамматических, включая словообразовательные и синтаксические, норм по формату 2026 года; удаление верного сочетания из колонки «Неверно». |
| 9 | Удаление слова «горы» как ложного примера корня -гар-/-гор-; замена устаревшего «зоревать» на «заревать»; лишняя кавычка в теме И/Ы после Ц. |
| 13 | Разведение правил написания НЕ и выбора НЕ/НИ в местоимениях и наречиях. |
| 26 | Точные границы ответа, требование всех названных средств и исключение не учитываемых ФИПИ приёмов; различение лексического повтора и формы слова. |

## Пробелы, требующие отдельной редакционной работы

- Задание 7: публично видна только одна тема. Перед добавлением остальных
  нужно проверить, не скрыты ли они сознательно в форме.
- Задание 8: вводный документ содержит пять опубликованных блоков, но открытых
  тем нет. Теперь каталог может показывать задание по наличию вводной теории;
  старые удалённые темы автоматически не возвращаются.
- Задание 13: публично видны две темы; отдельно не раскрыта практика
  различения НЕ с глаголами и причастиями. Следует проверить скрытые темы.
- Задание 14: в публичном каталоге нет самостоятельной темы про производные
  предлоги и наречия, хотя они названы во вводном документе.
- Задание 22: публично видна только «Звукопись и ловушки», а тропы,
  лексические и синтаксические средства представлены лишь во вводной схеме.
  Исходный код содержит такие темы, поэтому прежде всего следует установить,
  скрыты ли они в актуальной базе намеренно.
- Задание 24: публичная теория очень короткая; надо сверить с реальным
  форматом заданий, но не раздувать её повтором материала из задания 3.

Это **не утверждение**, что остальные блоки безупречны: просмотр публичного
каталога и адресная проверка правил не равны построчной предметной экспертизе
каждого примера и исключения. Скрытые и удалённые темы намеренно не
возвращаются в каталог автоматически. Полный административный экспорт теперь
доступен для следующего этапа такой экспертизы.

## Публикация после проверки владельцем

На сервере, после обновления кода:

```sh
sudo docker compose run --rm backend python -m app.scripts.revise_theory_2026
sudo docker compose run --rm backend python -m app.scripts.revise_theory_2026 --execute
```

Первый вызов — подробный план: для каждого затронутого блока печатаются
различия между текущим содержимым и предлагаемой заменой; ничего не пишется.
Второй создаёт новые версии и публикует их **только после вашего просмотра**.
Если текст уже изменился в форме, оба вызова откажутся от записи; конфликт
нужно разобрать вручную, не форсируя замену.

## План очистки скрытых, удалённых и устаревших тем

Полный экспорт активной версии курса показывает 27 заданий, и у каждого уже
есть опубликованная вводная теория. Среди 277 тем — 81 `published`, 6
`published_manual`, 42 `deprecated` и 148 `deleted`. У задания 8 нет ни одной
видимой темы, но его вводная теория остаётся доступной.
Поимённые варианты переноса 29 связанных с практикой тем находятся в
`docs/theory-cleanup-plan-2026.md`.

Простое физическое удаление 190 невидимых тем небезопасно: на них ссылаются
29 **опубликованных** наборов практики и 1345 связей упражнений. Удаление
тем без переноса связей приведёт к потере тематических тренажёров или к
ошибке ограничения БД из-за существующих сессий. При этом уникальных
упражнений в 29 наборах нет: все они есть и в практике целого задания.
Некоторые из этих тем
совпадают по названию с актуальными, но большинству требуется отдельное
редакционное решение: привязать практику к существующей теме или создать
новую проверенную тему. В частности, для задания 7 потребуются темы форм
существительных, глаголов и числительных; для задания 13 — отдельные темы
НЕ с глаголами и причастиями. Не переносите их автоматически на произвольную
тему того же задания.

Текущий скрипт **не удаляет** темы. Он печатает полный план зависимостей:

```sh
sudo docker compose run --rm backend python -m app.scripts.revise_theory_2026 --cleanup-report
```

Чтобы увидеть также блоки текущей версии каждой невидимой темы:

```sh
sudo docker compose run --rm backend python -m app.scripts.revise_theory_2026 --cleanup-report --show-content
```

Это отдельный просмотр; `--execute` пока относится только к 11 адресным
редакторским исправлениям выше. Команды физического удаления нет намеренно:
сначала нужно утвердить соответствие 29 связанных тем и их новой структуры,
сохранить резервную копию, затем перенести связи и только после проверки
удалить старые записи.
