# Редактирование текста и таблиц в форме

Редакторы одинаково работают в обычной форме и в окне **«Изменения по коду» → «После»**. Данные остаются обычными блоками Пумрус и совместимы с экспортом JSON; миграция БД не требуется.

## Текст

Выделить фрагмент и нажать **B** (жирный), **I** (курсив), зачёркивание, код или ссылку. Повторное нажатие B/I снимает оформление. Если выделения нет, оформляется слово возле курсора; в пустом поле вставляется выделенный образец «текст», который можно сразу заменить.

**Ctrl+B / Ctrl+I / Ctrl+K** работают и при русской раскладке; на macOS используется Cmd. Ссылки добавляются через небольшое поле адреса. Для обычного текста также доступны маркированный и нумерованный список, цитата и снятие оформления выделения.

Панель сохраняет выделение и позицию прокрутки. Результат сразу виден в предпросмотре. Жирный можно сочетать с курсивом, в том числе в ячейках таблиц. Оформление хранится в Markdown, поэтому его можно исправлять вручную и передавать в пакетах изменений.

Авторская пометка свёрнута в отдельный раздел под основными полями. Если она уже есть, раздел отмечен «добавлена».

## Таблицы

Основной режим — **«Ячейки»**: у каждой ячейки собственное поле, строка и столбец обозначены номером и буквой. Выделенный фрагмент в активной ячейке можно оформить общей панелью.

| Действие | Как выполнить |
| --- | --- |
| Добавить строку или столбец | Кнопки под таблицей; вставка после активной строки/столбца |
| Удалить строку или столбец | Выбрать ячейку и нажать «Убрать…»; последняя строка/столбец защищены |
| Следующая / предыдущая ячейка | Tab / Shift+Tab; Tab в последней ячейке создаёт строку |
| Перенос внутри ячейки | Enter |
| Добавить строку с клавиатуры | Ctrl+Enter |
| Выйти из сетки к кнопкам | Esc |
| Вставить из Excel / Sheets | Скопировать диапазон и вставить в начальную ячейку; соседние ячейки заполнятся автоматически |
| Отменить / вернуть | Стрелки на панели или Ctrl+Z / Ctrl+Shift+Z; история хранит последние 100 правок |
| Строка заголовков | Переключатель «Первая строка — заголовок» |
| Выравнивание | Выбрать ячейку нужного столбца и направление под таблицей |

Настройки заголовка и выравнивания видны и в предпросмотре, и на странице ученика. По умолчанию первая строка остаётся заголовком, как в существующих таблицах. Горизонтальная прокрутка широких таблиц ограничена сеткой редактора.

В режиме **«Текст с |»** строки разделяются Enter, ячейки — `|`. Shift+Enter вставляет `\n` для переноса внутри ячейки; `\|` означает обычный символ `|`, `\\` — обратную косую черту. Введённый текст сохраняется буквально во время печати: пробел перед разделителем больше не вызывает пересборку поля и скачок курсора. При переключении из ячеек текст собирается из текущих данных таблицы.

Все правки остаются локальными до штатной публикации или кнопки **«Применить изменения»** в окне сравнения.
