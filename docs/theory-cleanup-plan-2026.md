# План окончательной очистки старых тем

Снимок полного административного экспорта от 16 сентября 2026 года.
Очистка ещё не выполнена. Решение владельца: удалить 29 тематических
подборок, потому что все их упражнения есть в наборах целых заданий.

## Как выполнить

Сначала проверьте актуальный бэкап PostgreSQL в `backups/postgres` и его
целостность (`gzip -t`); для очистки нужен бэкап, сделанный **до** удаления.
Затем на сервере из корня проекта:

```sh
sudo docker compose run --rm backend python -m app.scripts.cleanup_stale_theory
sudo docker compose run --rm backend python -m app.scripts.cleanup_stale_theory --execute --backup-confirmed
```

Первый запуск ничего не меняет. Второй выполняет очистку одной транзакцией.
Скрипт требует ровно 190 устаревших тем и 29 дублирующих наборов, проверяет
состав упражнений, ссылки из видимой теории и правила доступа. Сессии
перепривязываются к опубликованному набору целого задания; попытки и сами
упражнения не удаляются. При несовпадении проверки работа прерывается без
частичной очистки. Повторно `--execute` запускать не нужно.

## Что уже установлено

- У всех 27 заданий есть опубликованная вводная теория. Для задания 8 это
  пять содержательных блоков; текущий каталог скрывал его только потому,
  что все темы задания 8 находятся в статусах `deleted`/`deprecated`.
- В активной версии курса 277 тем: 87 видимых (`published` или
  `published_manual`), 148 `deleted`, 42 `deprecated`.
- На 29 удалённых тем всё ещё опираются 29 опубликованных наборов практики
  и 1345 связей упражнений. Удалять такие темы напрямую нельзя: каскадное
  удаление затронет практику, а существующие сессии могут заблокировать
  удаление набора.
- Проверка состава всех 29 наборов показала **0 уникальных упражнений**:
  каждое упражнение входит также в опубликованный набор целого задания.
  Все 1345 упражнений имеют связь с заданием, но не имеют альтернативной
  связи с видимой темой. То есть при удалении старых тематических наборов
  сами упражнения сохранятся, однако исчезнет отдельный тематический отбор.
- Публичный маршрут практики сейчас действительно возвращает эти 29
  наборов как `scopeRole=topic`, несмотря на удалённый статус темы. Это
  объясняет разрыв: тренажёр доступен, а связанная тема теории скрыта.
- Для остальных невидимых тем тоже надо проверить привязки платного доступа;
  они не являются обычным внешним ключом и требуют отдельной сверки.

## Принятое решение

На текущем этапе нужны **только тренажёры целого задания**. Удаляем 29
старых тематических наборов и 1345 ссылок на скрытые темы; сами упражнения
и история ответов остаются. Скрипт проверяет и перепривязывает практические
сессии, а при обнаружении правил доступа останавливается.

Если сохраняем **отработку отдельных тем** как ключевую возможность UmRus,
просто удалять наборы нельзя. Нужен перенос на актуальные видимые темы или
создание новых тем с проверенной теорией. Массовое возвращение старых тем
в статус `published` быстрее, но создаст дубли и восстановит материал,
который уже был удалён/устарел.

## Архив отвергнутой альтернативы: сохранять тематические тренажёры

«Новая тема» означает создать **новую опубликованную** тему с проверенной
теорией, перенести в неё набор и связи упражнений, проверить ссылки из
теории и только затем удалить старую тему. Просто вернуть статус старой
удалённой теме нельзя: это восстановит потенциально устаревший материал.

## Безопасный порядок фактической миграции

1. Выгрузить полный административный архив теории и практики с историей.
2. По строкам выше утвердить точные новые темы и проверить их теорию по ФИПИ‑2026.
3. При сохранении тематической практики: создать новые темы, опубликовать
   документы, перенести ссылки упражнений, наборы практики и правила платного
   доступа; сохранить идентификаторы упражнений и наборов, чтобы не разрушить
   сессии и прогресс. При отказе от тематической практики: проверить сессии
   и доступ, затем удалить только дублирующие тематические наборы.
4. Проверить каждый тренажёр и ссылки из теории; только после этого удалять
   190 невидимых тем и их старые документы/версии.
5. Повторить отчёт `--cleanup-report`: невидимых тем, связей с ними и
   потерянных наборов должно быть ноль.

До утверждения соответствий из таблицы скрипт делает **только просмотр**.
